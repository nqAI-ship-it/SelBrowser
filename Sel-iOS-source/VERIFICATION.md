# Проверка iOS

Обновлено 25 октября 2026 года.

## Версия 1.0.0

[GitHub Actions](https://github.com/nqAI-ship-it/SelBrowser/actions/runs/40169387589), исходный коммит `ce491297cd5c70043227993a463ab4c7d31375f5`, успешно выполнил компиляцию Debug для Simulator и Release для iPhone. IPA проверена на Windows: SHA-256 `852ced605f6a39d4c02028099580a37b8b25e86a0d5e64b1b78ee5ab034b9673`, размер 376604 байта, целостность ZIP, Info.plist, ARM64 Mach-O для iOS device и локальные ресурсы. SDK — iPhoneOS 18.5, минимальная iOS — 16.0.

После подписи через iLoader пользователь подтвердил установку и запуск на своём iPhone. Самостоятельное тестирование агентом на физическом телефоне не выполнялось.

## Обновление 1.1.0 (2)

В работу включены нижняя навигация, отдельный нативный экран вкладок и нативные настройки. Bundle ID `com.selbrowser.ios`, файл `Library/Application Support/SelBrowser/state.json` и существующие поля профиля сохранены для обновления поверх версии 1.0.0.

До успешного нового запуска GitHub Actions компиляция этой версии и новая IPA не подтверждены. Прежний успешный запуск относится только к 1.0.0.

Проверки пакета:

- Исходники новых нативных контроллеров включены в Xcode через синхронизируемую группу Sources.
- Стабильные Bundle ID и номер обновления проверяются валидатором.
- Локальные JavaScript-ресурсы и граница trusted shell / websites проверяются отдельно.
- Workflow не использует Apple secrets и работает только в публичном репозитории.
- Снимки реально запущенной Debug-сборки на iPhone/iPad создаются скриптом `capture-ios-previews.sh` и сохраняются отдельным артефактом.

На первой установленной обновлённой сборке проверить:

1. Сохранение закладок, истории, настроек и обычной сессии после обновления без удаления приложения.
2. Отсутствие вкладок сверху; открытие нижней кнопкой экрана карточек.
3. Выбор и закрытие средней/правой карточки; создание вкладки; поиск по карточкам; обычный/приватный режим.
4. Открытие настроек, изменение темы, поисковика и масштаба; сохранение после перезапуска.
5. Поиск и HTTPS-сайты; назад/вперёд; мобильный вид; клавиатура, поворот и safe area.
6. Загрузка файла и доступ к нему через Files.

Снимки симулятора не подтверждают сохранение профиля при реальном обновлении и поведение сайтов на физическом iPhone.

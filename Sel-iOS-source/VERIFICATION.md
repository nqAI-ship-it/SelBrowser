В `.build/ios11/previews` получены три smoke-отчёта — `iPhone-smoke.json`, `iPad-smoke.json`, `iPhone-compat-smoke.json`. Каждый содержит **15/15 успешных проверок**: закрытие средней и правой вкладки, сохранение выбранной вкладки, создание новой после закрытия последней, расположение нижней навигации, нативные меню и экраны вкладок/настроек, разрешение поисковых запросов, изоляция приватной сессии, чтение формата профиля 1.0 и отсутствие сохранения миниатюр на диск.

Два отчёта подтверждают `UIGlassEffect` на iPhone/iPad с runtime iOS **26+**, третий — совместимый материал на runtime **ниже iOS 26**. Точные версии runtime в отчётах не записаны; они здесь не утверждаются. Сохранено **18 PNG**: главная, вкладки, поиск по вкладкам с клавиатурой, настройки, ввод адреса и тёмная главная для трёх конфигураций.

На снимках поиска вкладок видна системная подсказка **QuickPath первого запуска**. Она перекрывает часть области клавиатуры и ограничивает визуальную оценку этого кадра; это не подтверждение ошибки интерфейса Sel.

Проверки пакета:

- Исходники новых нативных контроллеров включены в Xcode через синхронизируемую группу Sources.
- Стабильные Bundle ID и номер обновления проверяются валидатором.
- Локальные JavaScript-ресурсы и граница trusted shell / websites проверяются отдельно.
- Workflow не использует Apple secrets и работает только в публичном репозитории.
- Снимки реально запущенной Debug-сборки на iPhone/iPad созданы скриптом `capture-ios-previews.sh` и сохранены артефактом **SelBrowser-iOS-previews** указанного успешного запуска.

Физическое обновление **1.1** пока не проверено; пользователь подтвердил установку только **1.0**. На первой установленной обновлённой сборке проверить:

1. Сохранение закладок, истории, настроек и обычной сессии после обновления без удаления приложения.
2. Отсутствие вкладок сверху; открытие нижней кнопкой экрана карточек.
3. Выбор и закрытие средней/правой карточки; создание вкладки; поиск по карточкам; обычный/приватный режим.
4. Открытие настроек, изменение темы, поисковика и масштаба; сохранение после перезапуска.
5. Поиск и HTTPS-сайты; назад/вперёд; мобильный вид; клавиатура, поворот и safe area.
6. Загрузка файла и доступ к нему через Files.

Снимки симулятора не подтверждают сохранение профиля при реальном обновлении и поведение сайтов на физическом iPhone.

# Sel для iPhone

Нативный браузер для iOS 16+ на UIKit и WKWebView. Сохранено оформление Sel; сайты открываются отдельными WebKit-вкладками.

25 октября 2026 года сборки Xcode для симулятора и настоящего iPhone успешно завершены: [результат сборки и IPA](https://github.com/nqAI-ship-it/SelBrowser/actions/runs/40169387589).

## Скачать и установить

1. Откройте успешную сборку по ссылке выше и скачайте **Artifacts → SelBrowser-unsigned-IPA**. Артефакт хранится семь дней; после истечения срока запустите **Actions → Build iOS → Run workflow**.
2. Распакуйте ZIP: нужен **SelBrowser-unsigned.ipa**.
3. Подключите iPhone к Windows по USB и установите IPA через [Sideloadly](https://sideloadly.io/), используя свой Apple Account. Пароль и код вводите самостоятельно в программе.
4. Подтвердите доверие своему профилю и включите Режим разработчика по указаниям iPhone.

IPA не подписан: простое открытие файла на телефоне его не установит. Бесплатную подпись нужно обновлять каждые семь дней. Apple Account и сертификаты в GitHub не используются. Установка и работа на физическом iPhone пока не проверены.

SHA-256 первого IPA: `852ced605f6a39d4c02028099580a37b8b25e86a0d5e64b1b78ee5ab034b9673`.

## Сборка

Исходники находятся в `Sel-iOS-source/`. Workflow `.github/workflows/ios-build.yml` определяет эту папку автоматически, проверяет ресурсы и JavaScript, компилирует для симулятора и iPhone, затем сохраняет IPA и журналы. Сборка запускается при изменении исходников или вручную; приватные репозитории пропускаются, чтобы не расходовать платные macOS-минуты.

Есть вкладки с закрытием любой вкладки, иконки сайтов, история, закладки, приватные вкладки, сохранение сессии и загрузки. Chrome Sync и расширения Chrome не включены.

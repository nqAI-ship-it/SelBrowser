# Sel на iPhone с Windows

Рабочий путь: **исходники → сборка GitHub Actions → IPA → подпись и установка через iLoader**. Собственный Mac не требуется. Windows-файл Sel.exe — отдельная программа и не устанавливается на iPhone.

Версия 1.0.0 успешно собрана и, по сообщению пользователя 25 октября 2026 года, установлена через iLoader и запускается на iPhone. Обновление **1.1.1 (3)** также успешно собрано: [GitHub Actions run 40214368805](https://github.com/nqAI-ship-it/SelBrowser/actions/runs/40214368805), коммит `3a14cf699af5e31a4c5b48e79e912c39f0875557`. Его физическая установка и сохранение данных при обновлении ещё не проверены.

## 1. Получить новую IPA

Готовый проверенный файл уже находится в основной папке Windows-проекта: **SelBrowser-1.1.1-unsigned.ipa**, 487659 байт. SHA-256: `e005eabb741727b73afaf93c878e80747cdd37eead46b6ebcf92f17b1c31d40d`. Для установки этой версии повторная сборка не требуется. [Что изменилось в адаптации 1.1.1](ADAPTATION-1.1.1.md).

Этот же результат можно получить из артефакта **SelBrowser-unsigned-IPA** в [успешном запуске](https://github.com/nqAI-ship-it/SelBrowser/actions/runs/40214368805): внутри архива он называется `SelBrowser-unsigned.ipa`. Это имя упаковки; версия внутри файла — **1.1.1 (3)**.

Для следующих изменений:

В уже настроенном публичном репозитории [nqAI-ship-it/SelBrowser](https://github.com/nqAI-ship-it/SelBrowser) обновить исходники в `Sel-iOS-source/` и корневой `.github/workflows/ios-build.yml`. Сборка запускается автоматически. Ручной запуск: **Actions → Build iOS → Run workflow**.

После зелёного результата скачать артефакт **SelBrowser-unsigned-IPA** и распаковать из него `SelBrowser-unsigned.ipa`. Артефакт **SelBrowser-iOS-previews** содержит снимки новой версии в симуляторе; **SelBrowser-build-logs** — журналы Xcode. Если сборка завершилась ошибкой, готовность новой IPA не подтверждена.

Сборка работает на стандартном macOS runner публичного репозитория. Исходники публичны; Apple Account, пароли, сертификаты и профили подписи в GitHub не загружаются. [Условия GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

## 2. Подписать и установить

1. Используйте iLoader только с [официального сайта](https://iloader.app/) или из [репозитория nab138/iloader](https://github.com/nab138/iloader). На этом компьютере уже установлен iTunes с компонентами подключения Apple.
2. Подключите iPhone к ноутбуку по USB и разблокируйте. Если iOS спросит, подтвердите доверие именно своему компьютеру.
3. В iLoader выберите карточку **iPhone — USB**. Вход выполняйте тем же Apple Account, которым подписана уже установленная версия Sel.
4. Пароль и свежий код 2FA вводите самостоятельно в iLoader. Не передавайте их в чат и GitHub. Сохранение учётных данных необязательно.
5. Нажмите **Import IPA**, выберите **SelBrowser-1.1.1-unsigned.ipa** (либо `SelBrowser-unsigned.ipa` из указанного успешного запуска) и дождитесь завершения установки.
6. Откройте **Sel** на iPhone. Если iOS просит режим разработчика, включите его самостоятельно в **Настройки → Конфиденциальность и безопасность → Режим разработчика**, выполните перезагрузку и подтверждение. [Инструкция Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).

При необходимости подтвердите доверие своему профилю в **Настройки → Основные → VPN и управление устройством**. Простое открытие неподписанного IPA в приложении Files не устанавливает его.

## 3. Обновить существующий браузер

**Не удаляйте Sel перед обновлением.** Импортируйте новую IPA через iLoader поверх существующей программы с тем же Apple Account и идентификатором приложения. В исходниках обновления остаётся `com.selbrowser.ios`. При корректном обновлении iOS сохраняет контейнер приложения, однако инструменты подписи и изменения формата данных могут влиять на результат. Первое обновление с данными нужно проверить. [Пояснение Apple DTS](https://developer.apple.com/forums/thread/744934).

При смене аккаунта или идентификатора можно получить отдельное приложение либо отказ установки вместо обновления. Сначала сохраните важные данные, если планируете такую смену.

## 4. Срок бесплатной подписи

Профиль бесплатного Apple Account действует **7 дней**. До истечения срока снова подпишите и установите IPA через iLoader. Для обновления подписи можно использовать ту же версию IPA; новые функции требуют нового файла. Apple также ограничивает число одновременно установленных приложений бесплатного аккаунта. [Ограничения Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/).

Автоматической доставки обновлений внутри Sel сейчас нет. Установка через App Store или TestFlight в этот рабочий процесс не входит.

Sideloadly остаётся альтернативным инструментом, но на этом компьютере вход через него завершался ошибкой `-80046`; переход на iLoader позволил установить приложение. Повторная переустановка компонентов Apple не является подтверждённым решением этой ошибки.

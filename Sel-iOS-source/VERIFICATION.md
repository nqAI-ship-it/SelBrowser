# Статус проверки

Подготовлено 24 октября 2026 года.

Проверено на Windows:

- Комплектность исходников и локальных ресурсов.
- Ссылки на 20 объектов Xcode-проекта и общую схему SelBrowser.
- XML Info.plist и схема, UIScene, доступ к Downloads через Files.
- AppIcon 1024×1024 RGB без прозрачности.
- Синтаксис JavaScript и сообщения реального iOS-адаптера в native bridge.
- Ручной workflow без подписи и без Apple secrets, только для публичных репозиториев.
- Состав исходного ZIP, включая .github, без Windows EXE и профилей.

Не выполнялось: компиляция Xcode, запуск симулятора и установка/проверка на физическом iPhone. Первую компиляцию выполнит GitHub Actions. Успешная компиляция не заменяет проверку на устройстве.

После установки проверить: поиск и HTTPS-сайт; закрытие любой из трёх вкладок; назад/вперёд; закладки и перезапуск; приватные вкладки; загрузку файла и отправку в Files; поворот экрана и клавиатуру.

# Sel для iOS

Нативный браузер для **iOS 16+** на UIKit и WKWebView. Сайты открываются отдельными WKWebView без iframe; интерфейс и ресурсы Sel хранятся локально.

## Обновление 1.1.0 (2)

- Нижняя навигация для iPhone и iPad вместо верхнего ряда вкладок.
- Настоящий системный Liquid Glass для адресной строки, навигации и управляющих кнопок на iOS 26+; совместимый материал для iOS 16–25.
- Отдельный экран вкладок с карточками, предпросмотрами страниц, поиском, закрытием любой вкладки и переключением обычного/приватного режима.
- Нативные настройки с поиском, списками выбора, темами, поисковой системой, масштабом и восстановлением сессии.
- Мобильный режим сайтов, безопасные отступы, поворот устройства и экранная клавиатура.

Идентификатор приложения остаётся `com.selbrowser.ios`, а расположение и формат пользовательского профиля сохранены. При обновлении используйте тот же Apple Account и установите новую IPA поверх существующего приложения. Не удаляйте браузер перед обновлением: вместе с удалением iOS удалит его локальные данные. Первое обновление с сохранением данных нужно проверить отдельно.

## Установка и обновление с Windows

Инструкция: [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md). Для готового обновления рабочий путь — **iLoader → Import IPA → SelBrowser-1.1.0-unsigned.ipa**, подключённый iPhone и тот же Apple Account. В облачный репозиторий не передаются пароли, сертификаты и профили подписи.

## Поддерживаемые функции

- Настоящие вкладки WebKit с постоянными ID, восстановлением и отдельными cookie обычного/приватного режима.
- Локальные история, закладки, настройки и сохранение обычной сессии.
- Иконки сайтов, открытия в новом окне, загрузки в Documents/Downloads и отправка файлов через системное меню.

Приватный режим не делает соединения анонимными. Скачанные файлы остаются на диске. В этой версии нет Google Sync, расширений Chrome, импорта HTML-закладок и отключения звука отдельной вкладки. Памятью iOS управляет WebKit.

## Разработка

Xcode 26.3 и SDK iOS 26+ для Liquid Glass; схема SelBrowser; Swift 5; минимальная iOS 16 с совместимым интерфейсом. [Подробности сборки](README-BUILD.md). [Нативный Liquid Glass и список изменений](LIQUID-GLASS.md).

```sh
python3 scripts/validate-package.py
node scripts/validate-shell.mjs
```

Эти проверки структуры и JavaScript не компилируют Swift. На macOS:

```sh
bash scripts/build-ios.sh --simulator-only
bash scripts/capture-ios-previews.sh
bash scripts/build-ios.sh
```

Результат — неподписанный `dist/SelBrowser-unsigned.ipa`. Подпись и установка выполняются локально собственным Apple Account.

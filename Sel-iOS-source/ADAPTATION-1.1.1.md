# Sel для iOS 1.1.1 (3): главная страница и адаптация

Обновление исправляет наложения интерфейса, показанные на снимке iPhone, и полностью меняет компоновку главной страницы. Прежний логотип Sel сохранён. Windows-интерфейс и Sel.exe не изменяются.

## Изменения по запросу

| Область | Изменение |
| --- | --- |
| Главная страница | Новая компоновка: приветствие с прежним логотипом, поисковая капсула с кнопкой отправки, быстрый доступ 2×2 на телефоне и четыре карточки в ряд на iPad, отдельная секция закладок. Поддержаны светлая, тёмная и футбольная темы. Узкий или короткий экран прокручивается вертикально; при вводе форма поиска удерживается в видимой области. |
| Адресная строка и верхняя панель | Поле адреса и кнопка настроек имеют отдельные постоянные колонки. Текст ограничен границами поля, размер строки учитывает системный шрифт. Сворачивание колонки настроек при вводе убрано. Веб-содержимое начинается ниже всей верхней панели. |
| Нижняя навигация | Панель закреплена у нижней безопасной границы устройства. В обычном режиме сайт заканчивается перед ней; при открытии закреплённой экранной клавиатуры панель скрывается, а область сайта заканчивается над клавиатурой. Панель больше не поднимается поверх сайта вслед за клавиатурой. |
| Клавиатура и дополнительная плашка | Для веб-страниц добавлен `BrowserWebView`: публичное переопределение `UIResponder.inputAccessoryView` возвращает `nil`, группы `inputAssistantItem` очищены. У нативного поля адреса дополнительный accessory view также отсутствует. Это изменение дополнительной панели форм браузера; сама клавиатура Apple и её системные клавиши не заменяются. Отсутствие панели форм дополнительно проверяется настоящим вводом в XCUITest. |
| Liquid Glass | Настоящий материал UIKit сохранён в адресной строке, навигации и системных управляющих кнопках. Подложки навигации непрозрачны и находятся вне области веб-страницы: текст сайта больше не должен читаться через адресную строку или кнопки. Сайты не получают CSS-имитацию стекла. |

Обычный поиск, быстрые ссылки, закладки и приватная заметка используют прежний безопасный мост локальной оболочки. Главная остаётся локальным HTML; навигация и настройки — UIKit; сайты — отдельные мобильные WKWebView.

## Совместимость и данные

- Минимальная версия — iOS/iPadOS 16.0. На iOS 26+ используется `UIGlassEffect`, на прежних версиях — совместимый системный материал.
- Bundle ID остаётся `com.selbrowser.ios`.
- Формат и расположение профиля сохраняются: `Library/Application Support/SelBrowser/state.json`.
- Обновление следует устанавливать поверх существующего Sel через iLoader с тем же Apple Account. Удаление приложения удаляет его локальные данные.
- Физическое обновление 1.1.1 на пользовательском iPhone ещё не проверено.

## Изменённые файлы

В репозитории исходники находятся в `Sel-iOS-source/`; локально соответствующая папка называется `ios/`.

1. `SelBrowser/Sources/BrowserViewController.swift` — отдельные области сайта и навигации, реакция на клавиатуру, локальные сценарии проверки.
2. `SelBrowser/Sources/MobileBrowserChrome.swift` — постоянные колонки адреса и настроек, ограничения текста, скрытие нижней панели.
3. `SelBrowser/Sources/BrowserWebView.swift` — публичная настройка дополнительной панели клавиатуры.
4. `SelBrowser/Resources/Shell.html` — новая адаптивная главная с прежним логотипом.
5. `SelBrowser.xcodeproj/project.pbxproj` — версия 1.1.1 (3) и цель UI-тестов.
6. `SelBrowser.xcodeproj/xcshareddata/xcschemes/SelBrowser.xcscheme` — включение UI-тестов в схему.
7. `SelBrowserUITests/BrowserKeyboardTests.swift` — проверки настоящих нажатий и ввода.
8. `scripts/capture-ios-previews.sh` — обновлённые сценарии и снимки симуляторов.
9. `scripts/run-ios-keyboard-tests.sh` — запуск XCUITest и сохранение результатов.
10. `scripts/validate-package.py` — комплектность нового исходного пакета и цели тестов.
11. `scripts/build-ios.sh` — обязательное включение нового `BrowserWebView` в комплект сборки.

Дополнительно изменён локальный `prepare-ios.ps1`, который воспроизводит новую главную без изменения Windows Shell, и добавлен этот `ADAPTATION-1.1.1.md`. Корневой GitHub workflow не изменялся.

# Sel на iPhone с компьютером Windows

Путь для личного тестирования: **исходники → сборка на GitHub → IPA → подпись и установка через Sideloadly**. Собственный Mac не требуется: Xcode запускается на облачном Mac. Windows-файл `Sel.exe` нельзя установить или переименовать в iOS-приложение; для телефона подготовлен отдельный проект на WebKit/WKWebView.

На этой стадии исходники подготовлены, но сборка Xcode и запуск на iPhone ещё не подтверждены. Устанавливать приложение можно после успешного запуска workflow и получения IPA. Требуется iPhone с iOS 16 или новее.

## 1. Получить IPA бесплатно

1. Распакуйте `Sel-iOS-source.zip` на Windows. Внутри должны быть `SelBrowser.xcodeproj`, папка `SelBrowser` и `.github/workflows/ios-build.yml`.
2. Войдите в GitHub и создайте новый **Public**-репозиторий, например `sel-ios`. Стандартные macOS runners GitHub Actions бесплатны для публичных репозиториев; в приватном репозитории действуют лимиты минут и возможные расходы. [Условия GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
3. Через **Add file → Upload files** загрузите **содержимое** распакованного архива в корень репозитория и сохраните изменения. Не загружайте архив как один ZIP и не вкладывайте весь проект в дополнительную папку `ios`: файл workflow должен оказаться по пути `.github/workflows/ios-build.yml` от корня репозитория.
4. Откройте **Actions → Build iOS → Run workflow**, выберите основную ветку и нажмите **Run workflow**. Если GitHub сначала предлагает разрешить workflows, подтвердите запуск для своего репозитория.
5. Дождитесь зелёной отметки успешной сборки. Откройте этот запуск и в разделе **Artifacts** скачайте **SelBrowser-unsigned-IPA**.
6. Распакуйте скачанный ZIP. Нужен находящийся внутри файл **SelBrowser-unsigned.ipa**.

В Public-репозитории исходники будут видны всем. Загружайте только содержимое подготовленного iOS-архива, а не всю Windows-папку Sel с профилями браузера. Apple Account, пароль, сертификаты и платёжные данные для облачной сборки не нужны.

Если workflow красный, IPA ещё не готов. Скачайте **SelBrowser-build-logs** или скопируйте первую ошибку из шага сборки и передайте её для исправления. Исходный ZIP не является приложением для установки.

## 2. Подписать и установить с Windows

1. Скачайте Sideloadly для Windows только с [официального сайта](https://sideloadly.io/). Программа поддерживает установку IPA с бесплатным Apple Account. На том же сайте указаны требуемые компоненты iTunes и iCloud из установщиков Apple. Версии Microsoft Store могут конфликтовать с ними — сначала сверяйтесь с текущей инструкцией Sideloadly, не удаляйте существующие приложения вслепую.
2. Подключите iPhone кабелем USB, разблокируйте его и подтвердите доверие к своему компьютеру, если телефон спросит.
3. Откройте Sideloadly, выберите свой iPhone и перетащите **SelBrowser-unsigned.ipa** в окно программы.
4. Введите свой Apple Account в самой программе и нажмите **Start**. Если появляется запрос пароля или двухфакторного кода Apple, вводите его самостоятельно в соответствующем окне. Не отправляйте эти данные в чат и не добавляйте их в GitHub.
5. После окончания установки откройте на iPhone **Настройки → Основные → VPN и управление устройством**. Найдите профиль своего Apple Account и подтвердите доверие именно ему. На iOS 16+ для приложений разработки также нужен **Режим разработчика** в разделе **Настройки → Конфиденциальность и безопасность**; включите его самостоятельно и выполните предложенные телефоном перезагрузку и подтверждение. [FAQ Sideloadly](https://sideloadly.io/faq.html), [инструкция Apple по Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).
6. Запустите **Sel** с главного экрана iPhone.

Sideloadly подписывает неподписанный IPA вашим аккаунтом. Простое открытие IPA в «Файлах» или копирование его на телефон подпись не заменяет.

## 3. Чтобы браузер продолжал запускаться

У бесплатной подписи срок действия **7 дней**; бесплатный профиль ограничивает число одновременно установленных приложений. Apple указывает до трёх приложений на устройстве. [Ограничения бесплатного аккаунта Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/).

До истечения подписи снова установите IPA через Sideloadly либо включите его автоматическое обновление подписи. Для автоматического обновления компьютер должен быть доступен программе, а iPhone — подключён по USB или настроенному Wi-Fi. Для обновления поверх существующего приложения сохраняйте тот же Apple Account и Bundle ID; это помогает сохранить локальные данные. Перед переустановкой важных данных желательно сделать их резервную копию. [Обновление и сохранение данных в Sideloadly](https://sideloadly.io/faq.html).

Платное членство Apple для этого личного пути не требуется. Обычная публикация в App Store и использование TestFlight относятся к Apple Developer Program со стандартной стоимостью **99 долларов США в год** или местной ценой. [Apple Developer Program](https://developer.apple.com/programs/).

Альтернатива Sideloadly — **AltStore Classic + AltServer для Windows**: [официальная установка](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Для этого пути нужен именно Classic, а не региональный магазин AltStore PAL.

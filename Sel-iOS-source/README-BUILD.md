# Сборка iOS

Проект `SelBrowser.xcodeproj`, общая схема **SelBrowser**, минимальная версия **iOS 16**. Используется UIKit и WebKit. Исходники в `SelBrowser/Sources` и локальные ресурсы в `SelBrowser/Resources` включаются в цель автоматически через синхронизируемые группы Xcode 16 и новее.

В Windows iOS-приложение не компилируется. Для бесплатной облачной сборки поместите **содержимое этой папки** в корень своего публичного GitHub-репозитория, включая скрытую папку `.github`. Затем откройте **Actions → Build iOS → Run workflow**. Автоматического запуска по каждому изменению нет.

Workflow сначала компилирует приложение для симулятора, затем для iPhone, и создаёт архив **SelBrowser-unsigned-IPA**. В нём находится `SelBrowser-unsigned.ipa` и файл SHA-256. При ошибке скачайте **SelBrowser-build-logs**. Артефакты сохраняются семь дней.

Бесплатность относится к стандартному GitHub-hosted runner в публичном репозитории. Исходники такого репозитория общедоступны. Этот workflow намеренно пропускает сборку в приватном репозитории, чтобы не расходовать потенциально платные macOS-минуты. Для приватного репозитория GitHub применяет лимит бесплатных минут и правила тарификации; иной вариант требует отдельной настройки. [Правила GitHub](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

Результат **не подписан** и не устанавливается прямым открытием файла на iPhone. Подпись выполняется локально в Windows через AltStore Classic либо Sideloadly собственным Apple Account. Ни Apple Account, ни пароль, ни сертификаты, ни токены App Store Connect этому workflow не нужны. Подробные шаги установки находятся в `INSTALL-WINDOWS.md`.

На Mac можно открыть проект в Xcode, выбрать свою Personal Team в Signing & Capabilities и запустить на собственном устройстве. Для проверки сборки без подписи:

```sh
bash scripts/build-ios.sh --simulator-only
bash scripts/build-ios.sh
```

Пакет будет в `dist/SelBrowser-unsigned.ipa`. Скрипт должен запускаться на macOS с Xcode; никакие npm-пакеты или сторонние UI-фреймворки не требуются.

На Windows проверяется структура проекта и файлов. Только успешный запуск workflow подтверждает компиляцию Swift и создание IPA; реальная установка и проверка на iPhone выполняются отдельно.

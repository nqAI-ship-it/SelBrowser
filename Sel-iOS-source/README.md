# Sel для iOS

Первая нативная версия браузера для **iOS 16+** на UIKit и WKWebView. Сохранены оформление и локальные ресурсы Sel; сайты открываются отдельными WKWebView, без iframe.

**Статус:** исходники подготовлены, структура Xcode-проекта и JavaScript проверены на Windows. Компиляция Swift, создание IPA и работа на iPhone ещё не подтверждены. Их нужно проверить через включённый workflow и установку на устройство.

## Установить с Windows

Полная инструкция: [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).

Кратко: загрузить содержимое проекта в корень публичного GitHub-репозитория → Actions → Build iOS → Run workflow → скачать SelBrowser-unsigned-IPA → установить полученный IPA через Sideloadly своим Apple Account. Исходники публичного репозитория будут общедоступны. Для облачной сборки Apple-учётные данные не нужны.

## Что перенесено

- Настоящие WebKit-вкладки с постоянными ID, закрытием любой вкладки, перестановкой и восстановлением закрытых.
- Сессия, темы, поисковая система, масштаб сайтов и поведение после закрытия вкладки.
- Локальные закладки и история с поиском.
- Обычные и приватные вкладки с отдельными хранилищами cookie.
- Иконки сайтов, открытия в новом окне, загрузки в Documents/Downloads и меню отправки файлов.

Приватный режим не делает соединения анонимными. Скачанные файлы остаются на диске. Функции Chrome Sync, расширений, импорта HTML-закладок и отключения звука отдельной вкладки в эту первую версию не включены. Памятью iOS управляет WebKit; переключатель приостановки из Windows заменён пояснением.

## Разработка и проверка

Xcode 16+; схема SelBrowser; Swift 5; минимальная версия iOS 16. Проект использует UIScene-жизненный цикл и локальные ресурсы. [Подробности сборки](README-BUILD.md).

Локальная проверка структуры и JavaScript при наличии Python и Node.js:

```sh
python3 scripts/validate-package.py
node scripts/validate-shell.mjs
```

Эти команды не проверяют компиляцию Swift. На macOS:

```sh
bash scripts/build-ios.sh --simulator-only
bash scripts/build-ios.sh
```

Второй скрипт создаёт dist/SelBrowser-unsigned.ipa. Неподписанный IPA нужно подписать своим аккаунтом для установки на iPhone. Не добавляйте в репозиторий пароли, сертификаты или provisioning profiles.
